تشغيل SQL — إنشاء الجداول والإعدادات
مطلوب ▼

بعد ما Supabase يخلص الإعداد، روح لـ SQL Editor وشغّل الكود ده:

  • من الـ sidebar اضغط SQL Editor
  • ضغط New query
  • انسخ الـ SQL الكامل من ملف CLAUDE.md (قسم Database Schema) والصقه هنا
  • ضغط RUN (أو Ctrl+Enter)
⚠️ بعد كده شغّل الـ SQL الإضافي اللي في CLAUDE.md في قسم "HUMAN ACTIONS NEEDED" — ده بيضيف الأعمدة الجديدة اللي تمت إضافتها.
-- هذا الكود موجود في CLAUDE.md — شغّله كاملاً -- بعده شغّل هذا: ALTER TABLE public.projects ADD COLUMN IF NOT EXISTS installation_id uuid REFERENCES public.profiles(id); ALTER TABLE public.documents DROP CONSTRAINT IF EXISTS documents_type_check; ALTER TABLE public.documents ADD CONSTRAINT documents_type_check CHECK (type IN ('contract','invoice','receipt','delivery_note','completion_photo','other','materials_request'));

الحصول على مفاتيح Supabase
مطلوب ▼

هتحتاج 3 قيم من Supabase علشان تحطهم على Vercel بعدين:

  • من Supabase اضغط Settings (في الـ sidebar)
  • ضغط API
  • احتفظ بالقيم دي:
# القيم اللي هتحتاجها NEXT_PUBLIC_SUPABASE_URL = https://[project-ref].supabase.co ↑ موجود في: Project URL NEXT_PUBLIC_SUPABASE_ANON_KEY = eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... ↑ موجود في: Project API keys → anon public SUPABASE_SERVICE_ROLE_KEY = eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9... ↑ موجود في: Project API keys → service_role (secret)
⚠️ service_role key سري جداً — لا تشاركه مع أي حد ولا تحطه في الكود مباشرة.

إضافة Environment Variables على Vercel
مطلوب ▼

قبل أول deploy، لازم تضيف المفاتيح اللي أخدتها من Supabase:

  • في صفحة الـ project على Vercel اضغط Settings
  • من القائمة اختار Environment Variables
  • أضف الثلاثة variables دي واحدة واحدة:
NEXT_PUBLIC_SUPABASE_URL = https://[project-ref].supabase.co NEXT_PUBLIC_SUPABASE_ANON_KEY = eyJ... (الـ anon key) SUPABASE_SERVICE_ROLE_KEY = eyJ... (الـ service_role key)
ℹ️ اختار All Environments (Production + Preview + Development) لكل variable.
  • بعد إضافة الـ 3 variables ضغط Deploy — Vercel هيبني ويرفع التطبيق

    ربط الدومين الخاص

    توجيه الدومين الحالي للمنصة
    ✓
    إضافة الدومين على Vercel
    مطلوب ▼
    • افتح مشروعك على Vercel
    • اضغط Settings → Domains
    • اكتب الدومين بتاعهم مثلاً: platform.samnan.com.sa
    • ضغط Add
    • Vercel هيديك الـ DNS records اللي محتاج تضيفها — احتفظ بيها للخطوة الجاية
    ℹ️ تقدر تضيف الدومين كده: samnan.com.sa (root) أو platform.samnan.com.sa (subdomain) — الـ subdomain أسهل في الإعداد.
    ✓
    تعديل DNS عند مزود الدومين
    مطلوب ▼

    افتح لوحة تحكم مزود الدومين (GoDaddy / Namecheap / سعودي / إلخ) وأضف الـ records دي:

    لو بتضيف Subdomain (مثلاً platform.samnan.com.sa):

    Type Name Value TTL
    CNAME platform cname.vercel-dns.com Auto

    لو بتضيف Root Domain (مثلاً samnan.com.sa):

    Type Name Value TTL
    A @ 76.76.21.21 Auto
    CNAME www cname.vercel-dns.com Auto
    ⏱️ الـ DNS بياخد من 5 دقايق لـ 24 ساعة عشان ينتشر — ده طبيعي. Vercel بيعمل SSL تلقائياً بعد ما الـ DNS يشتغل.
