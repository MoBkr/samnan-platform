# Requirements: منصة سمنان

**Defined:** 2026-06-21
**Core Value:** منتج شغّال واحترافي بجودة UI/UX عالية يُسلَّم للعميل.

## v1 Requirements

متطلبات milestone **v1.1 — تحسينات العرض والفلترة**. كل متطلب يُربط بـphase في الـroadmap.

### عرض الفاتورة (INV)

- [ ] **INV-01**: اسم الفاتورة يظهر بخط عريض (bold) وبارز في كرت الدفعة عند الإنشاء والعرض

### ملخص المشروع (SUMM)

- [ ] **SUMM-01**: زر «ملخص المشروع» يظهر للكوردنيتر والإدارة جنب أزرار حالة المشروع
- [ ] **SUMM-02**: الملخص يعرض قسم العميل والمشروع (الاسم، العميل، الموقع، رقم الحساب، النوع مع/بدون تركيب، الحالة، التواريخ)
- [ ] **SUMM-03**: الملخص يعرض القسم المالي (قيمة المشروع، المحصّل، المتبقي، نسبة التحصيل + قائمة الدفعات مع حالة كل دفعة مدفوع/غير مدفوع)
- [ ] **SUMM-04**: الملخص يعرض المواد والتركيب (حالة المواد + ملخص الأصناف، حالة التركيب، المدة المتوقعة، تقدّم المراحل، الفنيين المعينين)
- [ ] **SUMM-05**: الملخص يعرض الفريق والمرفقات (الكوردنيتر/المبيعات/مدير التركيب + عدد المستندات + آخر نشاط)
- [ ] **SUMM-06**: الملخص قابل للطباعة (زر طباعة/PDF بتنسيق نظيف)

### الفلترة والعرض (FILT)

- [ ] **FILT-01**: المستخدم يقدر يفلتر المشاريع برقم حساب العميل — عند إدخاله تظهر كل المشاريع التابعة لنفس العميل
- [ ] **FILT-02**: المستخدم يكتب عدد المشاريع المعروضة بنفسه (بدل 12/30/الكل الثابتة) ويُطبَّق تلقائيًا

### المواد (MAT)

- [ ] **MAT-01**: المستخدم يقدر يعدّل جدول المواد اليدوي بالكامل (إضافة/حذف أصناف) ويُحفظ
- [ ] **MAT-02**: بعد إدخال جدول المواد يدويًا والضغط «حفظ»، تظهر المواد فورًا (إصلاح bug: لا تظهر حاليًا)

## v2 Requirements

تعديلات إضافية أشار لها العميل وستُحدَّد في milestones لاحقة.

### لاحقًا (LATER)

- **LATER-01**: تعديلات إضافية متعددة (تُجمَّع وتُحدَّد عند طلبها)
