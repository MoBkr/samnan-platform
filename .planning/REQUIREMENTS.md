# Requirements: منصة سمنان

**Defined:** 2026-06-21
**Core Value:** منتج شغّال واحترافي بجودة UI/UX عالية يُسلَّم للعميل.

## v1 Requirements

متطلبات milestone **v1.1 — تحسينات العرض والفلترة**. كل متطلب يُربط بـphase في الـroadmap.

### عرض الفاتورة (INV)

- [x] **INV-01**: اسم الفاتورة يظهر بخط عريض (bold) وبارز في كرت الدفعة عند الإنشاء والعرض

### ملخص المشروع (SUMM)

- [x] **SUMM-01**: زر «ملخص المشروع» يظهر للكوردنيتر والإدارة جنب أزرار حالة المشروع
- [x] **SUMM-02**: الملخص يعرض قسم العميل والمشروع (الاسم، العميل، الموقع، رقم الحساب، النوع مع/بدون تركيب، الحالة، التواريخ)
- [x] **SUMM-03**: الملخص يعرض القسم المالي (قيمة المشروع، المحصّل، المتبقي، نسبة التحصيل + قائمة الدفعات مع حالة كل دفعة مدفوع/غير مدفوع)
- [x] **SUMM-04**: الملخص يعرض المواد والتركيب (حالة المواد + ملخص الأصناف، حالة التركيب، المدة المتوقعة، تقدّم المراحل، الفنيين المعينين)
- [x] **SUMM-05**: الملخص يعرض الفريق والمرفقات (الكوردنيتر/المبيعات/مدير التركيب + عدد المستندات + آخر نشاط)
- [x] **SUMM-06**: الملخص قابل للطباعة (زر طباعة/PDF بتنسيق نظيف)

### الفلترة والعرض (FILT)

- [x] **FILT-01**: المستخدم يقدر يفلتر المشاريع برقم حساب العميل — عند إدخاله تظهر كل المشاريع التابعة لنفس العميل
- [x] **FILT-02**: المستخدم يكتب عدد المشاريع المعروضة بنفسه (بدل 12/30/الكل الثابتة) ويُطبَّق تلقائيًا
- [x] **FILT-03**: المستخدم يقدر يفلتر طلبات الشراء بأكثر من خيار — رقم BR أو رقم التعميد (Release) أو اسم المشروع (أو المورّد)

### المواد (MAT)

- [x] **MAT-01**: المستخدم يقدر يعدّل جدول المواد اليدوي بالكامل (إضافة/حذف أصناف) ويُحفظ
- [x] **MAT-02**: بعد إدخال جدول المواد يدويًا والضغط «حفظ»، تظهر المواد فورًا (إصلاح bug: لا تظهر حاليًا)
- [x] **MAT-03**: جدول المواد بأعمدة جديدة: SAP No · الوصف · الكمية · STO No · حالة المنتج · ملاحظات · مرفقات (لكل صنف)
- [x] **MAT-04**: استيراد صفوف المواد من Excel عبر النسخ واللصق (positional، مع تجاهل صف العناوين عربي/إنجليزي) — اختياري بجانب الإدخال اليدوي
- [x] **MAT-05**: زر طباعة لقائمة المواد (للختم وإعادة الرفع كمرفق)
- [x] **MAT-06**: أعمدة المواد النهائية: SAP No · STO No · اسم الصنف · الكمية · الوحدة · ملاحظات · الحالة (مكتمل/قيد المعالجة/لم يطلب) · مرفقات — ولصق Excel بنفس الترتيب
- [x] **MAT-07**: إعادة تسمية «فاتورة المواد» إلى «مذكرة تسليم مواد»

### الدفعات (PAY)

- [x] **PAY-01**: عند إنشاء دفعة/فاتورة جديدة يمكن إرفاق أكثر من ملف في نفس اللحظة

### الملخص — تحسينات (SUMX)

- [x] **SUMX-01**: الملخص صفحة مستقلة (حرية تنقّل) بدل نافذة
- [x] **SUMX-02**: الضغط على دفعة/مرفق يفتح الفاتورة/المستند في نافذة عرض
- [x] **SUMX-03**: نِسب الإنجاز (إجمالي + التحصيل + المواد + التركيب) لكل قسم
- [x] **SUMX-04**: صفحة متابعة العميل تعرض المرفقات للعميل

### طلبات الشراء (PUR)

- [x] **PUR-01**: في إنشاء/تعديل طلب الشراء، يقدر يضيف أكثر من مرفق إضافي (بخلاف ملف المواد) — وتُحفظ هذه المرفقات في تاب «مرفقات» المشروع المرتبط بالطلب

## v2 Requirements

تعديلات إضافية أشار لها العميل وستُحدَّد في milestones لاحقة.

### لاحقًا (LATER)

- **LATER-01**: تعديلات إضافية متعددة (تُجمَّع وتُحدَّد عند طلبها)
