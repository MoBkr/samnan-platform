1 نظرة عامة والبنية التقنية

منصة ويب عربية RTL كاملة، مصممة خصيصاً لطريقة عمل سمنان للخدمات البترولية — بديل مركزي واحد عن ملفات الإكسل وجروبات الواتساب.

المنصة تدير دورة حياة المشروع كاملة: التعاقد ← الدفعة الأولى ← طلب المواد ← التوريد ← التركيب والمعاينات ← الدفعة النهائية ← الإغلاق. كل دور وظيفي يرى ما يخصه فقط، وكل عملية تُسجَّل وتُدقَّق.

البنية التقنية

  • الواجهة: Next.js 15 (App Router) + TypeScript + Tailwind CSS — تصميم عربي RTL بخط Cairo
  • الخلفية: Server Actions مع تحقق صلاحيات على السيرفر في كل عملية
  • قاعدة البيانات: Supabase (PostgreSQL) مع Row Level Security مفعّلة على كل الجداول
  • الملفات: Supabase Storage — رفع مباشر من المتصفح بروابط موقّعة (حتى 50MB للملف)
  • الاستضافة: Vercel (إنتاج) — قابلة للنقل لأي استضافة أو سيرفر خاص

مواصفات عامة

  • متجاوبة بالكامل: تعمل على الموبايل والتابلت والكمبيوتر
  • ثنائية اللغة: عربي / إنجليزي بضغطة زر لكل الشاشات
  • تصميم عصري: نظام تصميم موحّد (ألوان، ظلال، حركات انتقالية) بمستوى منصات SaaS العالمية
  • حالات تحميل وتنبيهات عربية واضحة في كل عملية
  • لا حذف نهائي عشوائي: أرشفة وتعطيل بدل الحذف، مع مسارات حذف آمنة للإدارة فقط

2 الأدوار والصلاحيات

أربعة أدوار وظيفية، وكل شاشة محمية على مستوى السيرفر — الرابط المباشر لا يفتح ما لا يخص المستخدم.

الدورالصلاحيات الأساسية
مهندس إدارة المشاريعإدارة كاملة لكل المشاريع: إنشاء، دفعات، مواد، تركيبات، طلبات شراء، إغلاق — هو المشغّل الرئيسي للمنصة
مهندس المبيعاتمشاريع عملائه فقط: إنشاء مشروع، تأكيد إرسال الفاتورة واستلام الدفع، طباعة الفواتير، اطّلاع على طلبات الشراء (قراءة فقط)
مدير التركيباتقسم التركيب بمشاريعه: المعاينات والمراحل، الفنيون، العهد المالية، المدونة، المرفقات والعقد (قراءة) — بدون ماليات، ومشاريع زملائه تظهر مقفولة
الإدارة العلياكل ما سبق + إدارة المستخدمين والموافقة على الحسابات + الاطّلاع على المدونات الشخصية (يُسجَّل في التدقيق) + التقارير

3 إدارة المشاريع

دورة حياة كاملة لكل مشروع الوحدة الأم

  • إنشاء مشروع بنموذج شامل: العميل، رقم حساب العميل الداخلي (للمحاسبة)، الموقع/المدينة، القيمة، التواريخ، نوع المشروع (مع تركيب / بدون تركيب — يتخطى خطوات التركيب تلقائياً)
  • رفع العقد PDF + مرفقات إضافية أثناء الإنشاء تذهب مباشرة لتاب المرفقات
  • تعيين فريق المشروع (مهندس إدارة، مبيعات، تركيبات) مع عرض حِمل العمل الحالي لكل شخص قبل التعيين
  • شريط مراحل حي: تعاقد ← دفعات ← طلب المواد ← توريد ← تركيب مجدول ← تركيب منجز ← إغلاق
  • رأس مالي مباشر: المحصّل / المتبقي / قيمة المشروع / نسبة إنجاز المواد / نسبة إنجاز التركيب
  • إجراءات الحالة: إغلاق (يمنع الإغلاق مع دفعات معلقة) — تعليق وإعادة تفعيل — إلغاء بسبب إلزامي — حذف نهائي آمن (للملغي/المعلق فقط، يمسح كل السجلات والملفات المرتبطة)
  • بحث وفلاتر متقدمة في قائمة المشاريع: بالاسم/العميل/رقم الحساب/المدينة/المهندس + فلتر حالة + تحديد عدد النتائج
  • تبويبات مشاريعي / كل المشاريع لكل دور
  • ملخص المشروع: صفحة نظرة عامة سريعة للإدارة (العميل والمالي والمواد والتركيب والفريق وأهم المرفقات وآخر نشاط) قابلة للطباعة عربي/إنجليزي
  • تعديل معلومات وقيمة المشروع في أي وقت مع تسجيل التغيير في التدقيق

4 الدفعات والفوترة

إدارة مالية كاملة لكل مشروع أكثر الوحدات تفصيلاً

  • جدول دفعات مرن: دفعة أولى / مواد / تركيب / نهائية / مخصصة — مع السماح بأكثر من دفعة من نفس النوع، وعنوان ثانوي اختياري لكل دفعة
  • تسجيل التحصيل: كامل أو جزئي مع شريط تقدم، رفع إيصال الدفع + مرفقات إضافية (فاتورة، ضمان...)
  • حماية الدفع الزائد: لو العميل دفع أكثر من المتفق عليه — تنبيه + ملاحظة إلزامية توضح السبب + تأكيد صريح، ثم ترتفع قيمة الدفعة ويتسجل كل شيء في التدقيق
  • تعديل شامل لأي دفعة: كل حقل قابل للتصحيح بمافيه الحالة نفسها (لو حد سجّل دفعة بالغلط) مع إعادة احتساب تلقائية
  • بيانات الفاتورة الضريبية: رقم الفاتورة (مع زر نسخ لنظام SAP)، تاريخ الفاتورة، اسم الشركة/البائع
  • حالة الفوترة والتحصيل: تم الفوترة / تم التحصيل / تم الاثنين — تظهر شارة على الكارت
  • خطاب الاعتماد LC: تفعيل لكل دفعة مع تاريخ الدفع وعدد الأيام — والمنصة تحسب تاريخ الاستحقاق وترسل تنبيهاً تلقائياً لمهندس إدارة المشاريع عند حلوله
  • تذكيرات آلية بالدفعات المستحقة لمهندس الإدارة والمبيعات
  • تأكيد مزدوج من المبيعات: "تم إرسال الفاتورة للعميل" و"العميل دفع المبلغ" — متاح لمهندس المبيعات المسؤول فقط
  • طباعة فاتورة رسمية لأي دفعة مدفوعة — عربي أو إنجليزي — على الورق الرسمي بشعار سمنان مع ختم PAID وخانات التوقيع
  • كشف متأخرات عام: صفحة المدفوعات تجمع المتأخر من كل المشاريع

5 المواد والتوريد

من طلب المواد حتى مذكرة التسليم الرسمية متوافقة مع SAP

  • أعمدة مطابقة لتصدير SAP: Purchasing Document · Material · Short Text · Order Quantity · Order Unit + مرفقات لكل صنف
  • استيراد Excel ذكي: رفع ملف القالب يُقرأ 100% — مع محرك تحليل يتعرف على الأعمدة تلقائياً (عربي أو إنجليزي، مع أو بدون عناوين) وشاشة مراجعة لتصحيح أي عمود قبل الاستيراد — لا يدخل صنف إلا بعد الضغط على «استيراد»
  • لصق مباشر من Excel: نسخ صفوف ولصقها في الجدول يوزعها على الأعمدة تلقائياً
  • قالب Excel جاهز بالأعمدة الصحيحة وأمثلة، بضغطة زر
  • حالة الصنف: مكتمل (افتراضي) / قيد الإجراء / لم يطلب (أحمر) — في الموقع فقط، لا تظهر في القالب ولا المطبوعات
  • مسار توريد بأربع خطوات مع إمكانية التراجع عن أي خطوة: طلب المواد ← جاهزة للتوريد ← التوريد والتسليم ← تم الاستلام
  • مذكرة تسليم مواد رسمية عربي/إنجليزي بالتنسيق المعتمد: جدول No. / SAP / DESCRIPTION / QTY / UNIT مع عمود MARK ✓ للتشييك اليدوي وصندوق توقيعات (التاريخ، الاسم، رقم الهوية، الجوال، التوقيع)
  • وصل الاستلام الموقّع من العميل يُرفع ويُحفظ — والتوريد لا يُحتسب مؤكداً في التقارير إلا به
  • التسليم قبل التحصيل مسموح (بقرار العميل) مع تذكير بأن دفعة المواد لم تُحصَّل
  • إنشاء دفعة المواد في تاب الدفعات بضغطة من نفس الشاشة
  • تاب "حالة المواد" بعرض ثنائي اللغة قابل للطباعة — لمشاركة الحالة مع العملاء الأجانب

6 التركيبات والمعاينات

مسار فحص هندسي من خمس مراحل أكبر وحدة

  • جدولة التركيب (لمهندس الإدارة): تاريخ البدء + تاريخ الانتهاء المتوقع + المدة المتوقعة — كلها قابلة للتعديل لاحقاً، مع تسجيل إبلاغ العميل
  • خمس مراحل معتمدة: فحص الموقع (بتأكيد بدء الفريق) ← معاينة المواد MIR (ميكانيكا / كهرباء / ملف شامل) ← معاينة التركيب WIR ← الاختبار والتشغيل ← قائمة الملاحظات Snag List
  • معاينة التركيب WIR ببنود قياسية: Tank، Pipe، Pressure Test، Conduit، Control Panel، Connection Generator، Cable Pulling، Cable Termination — كل بند يُعتمد أو يُرفض على حدة
  • نظام رفض متكامل: رفض بند أو مرحلة بسبب مكتوب و/أو مرفقات، مع منع إتمام مرحلة فيها بند مرفوض حتى حل المشكلة، وإمكانية «لا ينطبق» للبنود غير المطلوبة + إضافة بنود يدوية
  • ملفات لكل مرحلة وكل بند — صور ومستندات المعاينات تتوثق في مكانها
  • رجوع وإعادة فتح: أي مرحلة أو بند يمكن إعادة فتحه لتصحيح خطأ
  • مركز مشاريع التركيبات: مدير التركيبات يرى مشاريعه بتفاصيلها، ومشاريع زملائه تظهر مقفولة «ما عندك صلاحية» — مع إحصائيات تتبع الفلتر (مشاريعي / كل المشاريع)
  • عرض خاص لفريق التركيبات داخل المشروع: معلومات المشروع والعميل والمالي المسموح + تبويبات التركيب / المدونة / المرفقات

7 الفنيون

سجل فنيين مشترك بمنع تعارض الحجوزات

  • قائمة فنيين موحّدة للشركة (سجلات، ليست حسابات دخول): الاسم، الرقم الوظيفي، الحالة
  • صفحة /technicians: متاح / محجوز الآن، بحث، إضافة وتعديل وإيقاف وتفعيل (لا يمكن إيقاف فني محجوز)
  • تعيين لكل مشروع بفترة زمنية (من — إلى) مع منع التعارض تلقائياً: الفني المحجوز لا يُعيَّن على مشروع متداخل زمنياً
  • سجل تعيينات كامل لكل فني: أي مشروع ومتى، مع إنهاء التعيين (اكتمل) أو إزالته
  • إدارتها متاحة للتركيبات ومهندس الإدارة والإدارة العليا

8 العهد المالية

عهدة نقدية لمدير التركيبات بمحاسبة كاملة

  • استلام عهدة / صرف من العهدة مع ملخص حي: إجمالي العهدة — المصروف — المتبقي (يحمرّ لو بالسالب)
  • تصنيفات صرف: مواد خاصة للمشروع، سكن الفنيين، مواصلات، عدد وأدوات، أخرى
  • رقم فاتورة الشراء لكل مصروف + التاريخ + الصارف/المورّد + ملاحظات
  • فواتير وإيصالات مرفقة بكل سجل — وتظهر تلقائياً في مرفقات المشروع
  • كل حركة تُسجَّل في سجل التدقيق بالمبلغ والتصنيف — والحذف يُسجَّل أيضاً

9 طلبات المشتريات (BR)

لوحة متابعة المشتريات من الطلب حتى الاستلام

  • سبع مراحل: إنشاء الطلب ← موافقة المدير ← إدارة المخزون ← تعميد ← المالية ← Logistic ← تم الاستلام — بمسار مرئي وتواريخ لكل مرحلة
  • بيانات الطلب: رقم BR، رقم التعميد، المورّد، المهندس المسؤول، الموقع، الأولوية (مهم/متوسط)، تاريخ البدء وتاريخ الوصول المتوقع
  • قائمة المواد المطلوب شراؤها: جدول أصناف يدوي أو إرفاقها كملف PDF/صورة
  • مرفقات لكل مرحلة (عروض أسعار، تعميدات، أوامر شراء...)
  • ربط مباشر بالمشروع: الطلب يظهر داخل تاب "طلبات الشراء" في المشروع — وأي تعديل يتزامن بين اللوحة والمشروع، مع اختيار المشروع من نافذة بحث أنيقة (مشاريعي/كل المشاريع) أو «بدون مشروع»
  • إعادة فتح ذكية لأي مرحلة: تفتح المرحلة المحددة فقط للتصحيح — المراحل التالية تبقى مكتملة بتواريخها، وزر واحد يرجع الطلب لمكانه
  • ترتيب تلقائي حسب تاريخ الوصول الأقرب فالأبعد + فلتر متأخر أحمر + فلاتر المراحل وبحث برقم BR/التعميد/المشروع/المورّد
  • نطاق طلباتي / كل الطلبات — ومهندس المبيعات يشاهد طلبات مشاريعه قراءة فقط

10 مدونة المشروع والمدونة الشخصية

مدونة المشروع بديل جروب الواتساب

  • محادثة جماعية لفريق المشروع بواجهة شبيهة بالشات
  • منشن @ لأي عضو — يوصله إشعار فوري
  • مهام وتذكيرات ومواعيد ذكية بتاريخ استحقاق — إشعار تلقائي للفريق عند حلول الموعد، وتعليم المهمة منجزة
  • تعديل وحذف رسائلك (والإدارة تدير الكل) + بحث داخل المدونة
  • متاحة لكل فريق المشروع بمن فيهم التركيبات والمبيعات المعيّنون

المدونة الشخصية (مدونتي)

  • دفتر خاص لكل موظف: ملاحظات، مهام، تذكيرات، مواعيد
  • إشعار في المنصة عند حلول موعد أي عنصر
  • خصوصية واضحة: لا يراها أي زميل — الإدارة العليا فقط تطّلع (قراءة دون تعديل) وكل اطّلاع يُسجَّل في سجل التدقيق ويعرفه الموظف
  • ظاهرة في القائمة الرئيسية لكل الأدوار

11 الإشعارات والتذكيرات

جرس إشعارات حي داخل المنصة

  • نقطة حمراء بعدد غير المقروء — والضغط على الإشعار يوديك لمكانه بالظبط
  • أحداث مغطاة: جدولة تركيب، تعيين فني، تعيينك على مشروع، جاهزية المواد، تسجيل دفعة، تأكيدات المبيعات، منشن في مدونة، مهمة/تذكير حان موعده
  • تذكيرات مالية آلية: دفعة استحق موعدها، وخطاب اعتماد LC حان استحقاقه — تصل لمهندس الإدارة والمبيعات (مرة واحدة لكل حدث، بدون تكرار مزعج)
  • تعليم الكل كمقروء بضغطة

12 لوحات التحكم

لوحة مخصصة لكل دور

  • مهندس إدارة المشاريع: يحتاج إجراءً الآن (مهمة محددة لكل مشروع حسب مرحلته)، المتأخرات، تركيبات اليوم، الملخص المالي بشرائح الحالات، مراحل المشاريع المجمعة
  • الإدارة العليا: نظرة تنفيذية شاملة — كل المشاريع والفريق والتوزيع والمتأخرات وقيمة الأعمال
  • مهندس المبيعات: مشاريعه وقيمتها (كارت القيمة الموحّد: النشط + المعلق فقط، والملغي «غير محتسب» بتفصيل قابل للتوسيع)
  • مدير التركيبات: تركيبات اليوم والقادمة، ما لم يبدأ، ومركز مشاريعه — بإحصائيات تتبع فلتر مشاريعي/الكل
  • كل الكروت قابلة للضغط وتودي للقسم الصحيح، والقيم تستثني الملغي من الإجماليات

13 التقارير والملخص السنوي

تصدير وطباعة رسمية للإدارة

  • الملخص السنوي: لكل سنة — مشاريع أُنشئت / اكتملت / أُلغيت، عمليات التوريد المؤكدة (بمذكرة تسليم فقط)، تركيبات مكتملة، المحصَّل خلال السنة، قيمة العقود الجديدة — بجدول مقارنة بين السنوات
  • تقرير المشاريع: كل المشاريع بالحالة والقيمة والفريق والتواريخ
  • تقرير المدفوعات: كل الدفعات بالمحصّل والمتبقي والاستحقاق
  • تقرير الحسابات / الموظفين وسجل النشاطات
  • طباعة / PDF على الورق الرسمي بشعار سمنان وتاريخ إصدار

14 سجل التدقيق

كل عملية على المنصة موثّقة — من فعلها ومتى

  • تغطية شاملة: المشاريع والدفعات والمواد والتركيبات والعهد والفنيين وطلبات الشراء والحسابات والمدونات — كل إنشاء وتعديل وحذف واعتماد ورفض وإعادة فتح
  • تصنيف ذكي: مشاريع / طلبات شراء / حسابات وموظفين / إداري — مع فلاتر بالمشروع والطلب والفترة الزمنية وبحث حر
  • تعديلات الدفعات تُسجَّل بالقيم القديمة ← الجديدة، وتغييرات الحسابات (اسم، جوال، كلمة مرور) تُبلَّغ للإدارة
  • طباعة رسمية للسجل المفلتر بتوقيت السعودية
  • في الوضع الإنجليزي يظهر ثنائي اللغة: الإجراء بالإنجليزية والأسماء كما أُدخلت

15 صفحة متابعة العميل

رابط مشاركة خارجي بدون تسجيل دخول واجهة العميل النهائي

  • زر «مشاركة مع العميل» يولّد رابطاً آمناً برمز فريد — للعرض فقط، ولا يصل لأي بيانات داخلية
  • ثنائية اللغة عربي/إنجليزي بزر تبديل — للعملاء الأجانب
  • يعرض: مراحل المشروع والمرحلة الحالية، جدول الدفعات وحالتها، نسب المحصّل/المتبقي/الإجمالي، حالة المواد بالأصناف والكميات، وتقدم التركيب — تحديث مباشر من المنصة
  • معاينة الصفحة كما يراها العميل قبل الإرسال

16 الطباعة والمستندات الرسمية

كل مطبوعات المنصة على الورق الرسمي

  • ترويسة موحّدة بشعار سمنان للخدمات البترولية على رأس كل مستند
  • المستندات: الفاتورة الضريبية (بختم PAID وخانات توقيع)، مذكرة تسليم المواد (بالتنسيق الرسمي المعتمد)، قائمة المواد (عرضي A4)، ملخص المشروع، حالة المواد، التقارير، سجل التدقيق
  • اختيار اللغة قبل الطباعة عربي / إنجليزي حيثما يلزم
  • تقويم أنيق لاختيار التواريخ بضغطة في كل حقول المنصة، والتواريخ بارزة بالأزرق الداكن (والمتأخر أحمر) في كل الشاشات

17 الترجمة عربي / إنجليزي

المنصة كاملة تتحول للإنجليزية بضغطة زر

  • زر EN / عربي في رأس كل صفحة (وفي شاشات الدخول) — الاتجاه يتبدل RTL ⇄ LTR والاختيار محفوظ للمستخدم
  • قاموس شامل يتجاوز 1,000 عبارة يغطي كل شاشة ورسالة وتنبيه في المنصة
  • محرك ترجمة ذكي: يترجم الواجهة فورياً مع بقاء بيانات المستخدمين كما أُدخلت (أسماء المشاريع والعملاء والملاحظات لا تُمس) — وحماية خاصة تمنع أي ترجمة جزئية مشوّهة للأسماء
  • سجل التدقيق ثنائي اللغة في الوضع الإنجليزي: الإجراءات بالإنجليزية والأسماء بالعربية
  • المطبوعات الرسمية لها اختيار لغة مستقل لا يتأثر بلغة الواجهة

18 المستخدمون والملف الشخصي

إدارة المستخدمين (للإدارة)

  • موافقة على الحسابات الجديدة: من يسجّل بنفسه لا يدخل حتى توافق الإدارة — مع عرض الإيميل للتحقق من الهوية قبل التفعيل
  • إنشاء مستخدم مباشرة بكلمة مرور، تعديل الأدوار، حذف الحسابات
  • إعادة تعيين كلمة المرور: توليد كلمة قوية تلقائياً مع زر نسخ لتسليمها للموظف
  • عمود البريد الإلكتروني لكل الحسابات

ملفي الشخصي (لكل موظف)

  • صورة شخصية، الاسم، رقم الجوال
  • تغيير كلمة المرور (بكلمة المرور الحالية) مع أزرار إظهار/إخفاء في كل حقول كلمات المرور بالمنصة
  • الشفافية: أي تغيير للاسم/الجوال/كلمة المرور يُسجَّل في التدقيق ويصل إشعار للإدارة
  • استعادة كلمة المرور بالإيميل من شاشة الدخول

19 الأمان والحماية

  • تحقق صلاحيات على السيرفر في كل عملية — تغيير الواجهة أو الرابط لا يمنح صلاحية
  • Row Level Security مفعّلة على كل جداول قاعدة البيانات، والكتابة عبر قناة خدمة محكومة
  • حماية المسارات: Middleware يعيد غير المسجّل للدخول، وكل دور لصفحاته فقط
  • رفع ملفات آمن: فحص النوع والحجم (50MB) على الطرفين، روابط رفع موقّعة قصيرة العمر، دعم PDF / صور / Excel / AutoCAD DWG-DXF
  • تنظيف مركزي للملفات: حذف أي سجل يمسح ملفاته من التخزين — لا ملفات يتيمة
  • حذف المشروع النهائي يمسح كل السجلات المرتبطة (دفعات، مواد، تركيبات، مدونة، عهد، إشعارات، ملفات) بترتيب آمن
  • كلمات المرور بمعايير Supabase Auth، واستعادتها برابط آمن منتهي الصلاحية
