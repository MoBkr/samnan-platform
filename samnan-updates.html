💳 إدارة الدفعات

حذف وتعديل الدفعات
🆕 جديد ▼
❌ قبل
  • لا يوجد زر حذف للدفعة
  • لا يمكن تعديل المبلغ أو التاريخ بعد الإنشاء
  • الدفعة المدفوعة بالكامل قابلة للإضافة مرة أخرى بنفس النوع
✅ بعد
  • زر حذف (🗑) على كل دفعة — مع تحذير قبل حذف المدفوعة
  • زر تعديل (✏) يفتح نافذة لتغيير المبلغ والتاريخ والملاحظات
  • نوع الدفعة المدفوعة بالكامل يصبح معطّلاً في قائمة الإضافة
🔒
قاعدة الحماية لا يمكن تعديل دفعة مؤكدة الدفع (لحماية سجلات المحاسبة). الحذف متاح مع رسالة تحذير واضحة.
دفعة المواد — نوع جديد
🆕 جديد ▼
❌ قبل
  • أنواع الدفعات: أولى / توريد / تركيب / نهائية / مخصصة
  • لا يوجد نوع مخصص للمواد
✅ بعد
  • تمت إضافة "دفعة المواد" كنوع مستقل
  • تاب المواد مقيّد — لا يفتح إلا بعد تأكيد دفع هذه الدفعة
منع تكرار أنواع الدفعات
🔧 إصلاح ▼

إذا كانت هناك دفعة من نوع معين (مثلاً: الدفعة الأولى) بحالة "مدفوعة بالكامل"، فإن نفس النوع يظهر باللون الرمادي وغير قابل للاختيار في نافذة الإضافة — مع رسالة توضيحية. لا يمكن تجاوز هذا القيد إلا بحذف الدفعة القديمة أولاً.

⚙️ سير العمل — المواد والتركيب

تاب المواد — إعادة تصميم كاملة
✅ محسّن ▼
❌ قبل
  • نموذج بسيط لطلب المواد فقط
  • لا يوجد إدخال يدوي للأصناف
  • لا يوجد وصل استلام
  • لا يوجد ربط بالدفعات
✅ بعد
  • مقيّد بدفعة المواد (لا يفتح قبل السداد)
  • إدخال يدوي للأصناف: الاسم + الكمية + الوحدة + ملاحظة
  • رفع PDF طلب المواد عند تحديدها كجاهزة
  • تأكيد الاستلام ← ثم رفع وصل الاستلام

مراحل تاب المواد:

1 رفع ملف طلب المواد (PDF) + إدخال الأصناف يدوياً
2 تحديد المواد كـ "جاهزة" مع رفع وثيقة التحضير
3 تأكيد استلام المواد ← الانتقال لمرحلة "موردة"
4 رفع وصل الاستلام الموقّع (في أي وقت بعد التأكيد)
تاب التركيب — إبلاغ العميل
🔧 إصلاح ▼
❌ قبل
  • حقل "لم يُبلَّغ العميل" كان للعرض فقط
  • لا توجد طريقة لتسجيل الإبلاغ من المنصة
✅ بعد
  • زر تفاعلي "إبلاغ العميل" يُفعّل حالة الإبلاغ في النظام
  • بعد الضغط يتحول لشارة زرقاء "تم إبلاغ العميل"
  • يُسجَّل في سجل النشاطات تلقائياً
صلاحية الكوردنيتر — إصلاح جوهري
🔧 إصلاح ▼
❌ قبل
  • أي كوردنيتر يمكنه إدارة أي مشروع
  • لا يوجد تمييز بين "مشروعي" و"مشروع غيري"
✅ بعد
  • الكوردنيتر يدير مشاريعه فقط (التي هو الكوردنيتر المعين عليها)
  • يرى بقية المشاريع بصلاحية قراءة فقط
  • لا يستطيع رفع مرفقات في مشاريع غيره

📈 صفحة التقارير — ميزة جديدة كاملة

🔐
للإدارة فقط صفحة التقارير متاحة فقط للمستخدمين بدور "الإدارة" (Admin). لا تظهر في قائمة باقي الأدوار.
أنواع التقارير المتاحة
🆕 جديد ▼
  • 📊
    تقرير المشاريع — اسم المشروع، العميل، الحالة، المبلغ، الكوردنيتر، المبيعات، تاريخ البدء
  • 💳
    تقرير الدفعات — المشروع، النوع، المبلغ، المحصّل، المتبقي، الحالة، تاريخ الاستحقاق
  • 👥
    تقرير الفريق — الاسم، الدور، الحالة (نشط/غير نشط)، تاريخ الانضمام
  • 📝
    سجل النشاطات — آخر 300 إجراء: التاريخ، المستخدم، المشروع، الإجراء
🖨️
تصدير PDF كل تقرير يحتوي على زر "طباعة / تحميل PDF" يفتح print dialog المتصفح. يعرض PDF نظيف يحتوي فقط على بيانات التقرير مع هيدر يحمل اسم الشركة وتاريخ الإصدار.
بطاقات الإحصائيات في كل تقرير
🆕 جديد ▼

فوق كل جدول توجد بطاقات ملخص تعرض الأرقام المهمة دفعة واحدة:

  • 📊 تقرير المشاريع: إجمالي / نشطة / مكتملة / معلقة / إجمالي القيمة
  • 💳 تقرير الدفعات: عدد الدفعات / مكتملة / متأخرة / المحصّل من الإجمالي
  • 👥 تقرير الفريق: إجمالي الأعضاء / نشطون / غير نشطين
